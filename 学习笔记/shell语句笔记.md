# 第0章 Shell 脚本是什么？怎么写？怎么跑？

## 0.1 概念
平时你在终端一行行敲的命令，如果把它们**按顺序写进一个文件**，这个文件就是 **Shell 脚本**。
以后只要运行这个文件，里面的命令就会**从上到下自动依次执行**，不用再一行行敲了。

## 0.2 脚本文件的标准结构

```bash
#!/bin/bash
# 第一行必须写这个：声明用 bash 来解释执行
# 以 # 开头的行是注释，解释器会忽略，是写给人看的
echo "你好，Shell！"
pwd
ls
```

📌 三行话记住：
- 第一行 `#!/bin/bash` 是"声明头"，固定写法
- `#` 开头的是**注释**，不执行，用来给自己做说明
- 其余每一行就是一条命令，从上往下执行

## 0.3 运行脚本的两种方式

```bash
# 方式一（新手最推荐）：用 sh 来跑，不需要额外权限
sh 脚本名.sh

# 方式二：先给执行权限，再直接运行
chmod +x 脚本名.sh    # chmod 是修改权限，+x 是加上"可执行"
./脚本名.sh
```

⚠️ 方式二为什么前面要写 `./`？
因为直接敲 `脚本名.sh`，系统会去系统路径里找，找不到你当前目录的文件。
`./` 表示"就在当前目录里"，告诉系统：帮我跑当前目录下这个文件。

## 0.4 写脚本的完整流程（三件套）

```bash
vim my.sh          # 第1步：用 vim 创建并编辑文件
# 在 vim 里：按 i 进入编辑 → 粘贴或输入内容 → 按 Esc → 输入 :wq 回车保存退出

sh my.sh           # 第2步：运行它
# 第3步：看输出结果，错了就回去改
```

# 第1章 变量（脚本的"内存条"）

## 1.1 什么是变量
变量就是**给数据起个名字**，存在名字里，后面随时可以取出来用。

## 1.2 定义和使用的规则

```bash
# 定义：变量名=值（⚠️ 等号两边绝对不能有空格！）
name=tom
age=20
my_home=/root

# 使用：前面加 $ 符号
echo $name        # 输出 tom
echo "我的名字是 $name"    # 输出 我的名字是 tom
echo "${name}同学"          # 用 {} 把变量名括起来，防止歧义
```

```bash
# 演示：name 和 nameX 的区别
name=tom
echo "$nameX"     # 错误！Shell 会认为变量名叫 nameX（没定义，输出空）
echo "${name}X"   # 正确！输出 tomX
```

📌 规则总结：
| 规则 | 示例 | 说明 |
|------|------|------|
| 等号两边无空格 | `age=20` | 有空格会报错或当成命令 |
| 取值要加 $ | `echo $age` | 不加 $ 就只是输出字母 |
| 字符串可以不加引号 | `name=tom` | 没有特殊字符时可以 |
| 推荐加引号 | `name="tom"` | 有空格或符号时**必须**加引号 |

## 1.3 双引号 vs 单引号（重要区别！）

```bash
name=tom
echo "你好 $name"     # 双引号：里面的 $name 会被翻译 → 你好 tom
echo '你好 $name'     # 单引号：里面的东西原样输出 → 你好 $name
```

口诀：**双引号会"翻译"，单引号"原样照打"**。

## 1.4 特殊变量（系统已经帮我们定义好的）

| 变量 | 含义 |
|------|------|
| `$HOME` | 当前用户的家目录（root是/root，普通用户是/home/xxx） |
| `$PATH` | 命令的搜索路径 |
| `$USER` | 当前用户名 |
| `$0` | 当前脚本的名字 |
| `$1 $2 ...` | 运行脚本时传入的第1个、第2个参数 |
| `$#` | 一共传了多少个参数 |
| `$?` | 上一条命令是否成功（0=成功，非0=失败） |

```bash
#!/bin/bash
# 演示位置参数：保存为 args.sh 后运行  sh args.sh a b c
echo "脚本名：$0"
echo "第1个参数：$1"
echo "第2个参数：$2"
echo "参数个数：$#"
```

# 第2章 算术运算 $(( ))（让 Shell 会算数）

## 2.1 核心概念
Shell 里普通的 `=` 只是"存东西"，**不会做数学计算**。

```bash
sum=1+2
echo $sum        # 输出的是 1+2（字符串），不是 3！
```

想让 Shell 真的算数，必须用 `$(( ))`：

```bash
sum=$(( 1 + 2 ))
echo $sum        # 输出 3
```

## 2.2 支持的运算符号

| 符号 | 意思 | 例子 |
|------|------|------|
| `+` | 加 | `$(( 5 + 3 ))` → 8 |
| `-` | 减 | `$(( 5 - 3 ))` → 2 |
| `*` | 乘 | `$(( 5 * 3 ))` → 15 |
| `/` | 除（整数） | `$(( 5 / 2 ))` → 2 |
| `%` | 取余数 | `$(( 5 % 2 ))` → 1 |

## 2.3 用变量的累加写法（后面循环必备）

```bash
i=1
i=$(( i + 1 ))      # 把 i 原来的值 +1 再存回 i
echo $i             # 输出 2

# 更高级的简写（了解即可）
(( i++ ))           # i 自增1
(( i += 5 ))        # i 自己加5
```

```bash
# 完整例子：算两个变量的和
a=10
b=20
sum=$(( a + b ))
echo "总和是 $sum"     # 输出 总和是 30
```

> 🔑 记住这节就一句话：**在 Shell 里要算数，就套上 `$(( ))`。**

# 第3章 条件判断：test 和 [ ]（脚本的"眼睛"）

## 3.1 概念
程序要学会"看情况办事"，靠的就是条件判断。
Shell 判断条件的两种写法**完全等价**：

```bash
test 条件
[ 条件 ]
```

⚠️⚠️ 最最常见的报错来源：`[ ]` 的**两边必须有空格**！
```bash
[条件]    # ❌ 错误
[ 条件 ]  # ✅ 正确
```

## 3.2 判断数字大小（重点中的重点）

| 写法 | 英文全称 | 意思 |
|------|---------|------|
| `[ a -eq b ]` | equal | a 等于 b |
| `[ a -ne b ]` | not equal | a 不等于 b |
| `[ a -gt b ]` | greater than | a 大于 b |
| `[ a -lt b ]` | less than | a 小于 b |
| `[ a -ge b ]` | greater or equal | a 大于等于 b |
| `[ a -le b ]` | less or equal | a 小于等于 b |

```bash
# 数字比较必须用这些带 - 的写法，不能直接写 > < =
[ 20 -gt 10 ] && echo "20大于10"     # 会输出
[ 5 -gt 10 ] && echo "5大于10"        # 不输出（条件为假）
```

## 3.3 判断字符串

```bash
# 字符串相等用 = （单个等号），注意和数字比较区分！
[ "$a" = "$b" ]       # 相等
[ "$a" != "$b" ]      # 不相等
[ -z "$a" ]           # a 是否为空字符串（zero）
```

⚠️ 判断字符串时，变量最好加双引号：`[ "$a" = "$b" ]`
这样即使 a 是空的，也不会因为写法问题报错。

## 3.4 判断文件类型

| 写法 | 意思 |
|------|------|
| `[ -e 文件 ]` | 存不存在（exist） |
| `[ -f 文件 ]` | 是不是普通文件（file） |
| `[ -d 文件 ]` | 是不是目录（directory） |
| `[ -r 文件 ]` | 是否可读 |
| `[ -w 文件 ]` | 是否可写 |
| `[ -x 文件 ]` | 是否可执行 |

```bash
[ -e /etc/passwd ] && echo "这个文件存在"
[ -d /etc ] && echo "/etc 是目录"
[ -f /etc ] && echo "/etc 是普通文件"     # 不会输出，因为它是目录
[ -d /root ] && echo "/root 是目录"       # 会输出
```

## 3.5 && 和 ||（把判断串起来用）

```bash
命令1 && 命令2    # 命令1 成功了才执行 命令2（并且）
命令1 || 命令2    # 命令1 失败了才执行 命令2（或者）
```

```bash
[ -d /etc ] && echo "是目录" || echo "不是目录"
# 前面的为真→执行 && 后面的；为假→跳到 || 后面
```

> 🔑 第3章一句话总结：
> **数字用 -eq/-ne/-gt/-lt/-ge/-le，字符串用 = !=，文件用 -e/-f/-d**
> **条件判断目前还不"干活"，它是给第4章的 if 当"大脑"用的。**

# 第4章 if 分支（根据条件做不同的事）

## 4.1 单分支 if
格式：满足条件就做，不满足就**跳过**。

```bash
if [ 条件 ]
then
    要执行的命令      # 条件为真才执行
fi                    # fi = if 反过来写，表示 if 结束，必须有！
```

```bash
#!/bin/bash
# 例子：判断 /etc 是不是目录
if [ -d /etc ]
then
    echo "/etc 是一个目录"
fi
```

## 4.2 双分支 if-else
格式：条件为真做A，否则做B，**二选一，必执行一个**。

```bash
if [ 条件 ]
then
    命令1          # 为真执行这里
else
    命令2          # 为假执行这里
fi
```

```bash
#!/bin/bash
# 例子：成绩是否及格
score=85
if [ $score -ge 60 ]
then
    echo "及格，继续加油"
else
    echo "不及格，需要补考"
fi
```

## 4.3 多分支 if-elif-else
格式：从上往下逐个检查，**命中哪个就执行哪个，然后整个结束**。

```bash
if [ 条件1 ]
then
    命令1
elif [ 条件2 ]
then
    命令2
elif [ 条件3 ]
then
    命令3
else
    命令4       # 以上全部不满足才执行
fi
```

```bash
#!/bin/bash
# 例子：成绩评级
score=85
if [ $score -ge 90 ]; then
    echo "优秀"
elif [ $score -ge 60 ]; then
    echo "及格"
else
    echo "不及格"
fi
```

## 4.4 if 和 then 写在一行的技巧

```bash
# 多行写法
if [ $score -ge 90 ]
then
    echo "优秀"
fi

# 单行写法（用 ; 分号隔开）
if [ $score -ge 90 ]; then
    echo "优秀"
fi
```

📌 `;` 分号的作用：**在一行里分隔两条命令**，相当于换行。

## 4.5 判断结构记法小结

```
if        → 开始
then      → "那么"
elif      → "否则如果"
else      → "否则"
fi        → 结束（必须写！）
```

> 🔑 最容易犯的错：**写了 if 忘了结尾的 fi**。一报错就先去检查 fi。

# 第5章 case 多分支（比一长串 elif 更清爽）

## 5.1 什么时候用 case
当你要判断"**这个变量到底等于哪个固定值**"，比如等于1做什么、等于2做什么，用 case 最合适。它就像一个大号"开关"。

## 5.2 语法格式

```bash
case $变量 in
"值1")
    命令1
    ;;              # 双分号：这一支执行完，整个 case 结束
"值2")
    命令2
    ;;
*)                  # 星号通配：匹配"其他所有情况"，相当于 else
    默认命令
    ;;
esac                # 结束标记！是 case 倒过来写：esac
```

⚠️ 三个必须记住的点：
1. 每支结尾要有 `;;`（两个分号）
2. 最后要有 `*）` 当"其他情况"
3. 结尾是 **esac**（case 倒过来），不是 fi！

## 5.3 完整例子

```bash
#!/bin/bash
# 给水果说中文名
read -p "请输入一个水果的英文名: " fruit
case $fruit in
"apple")
    echo "🍎 苹果"
    ;;
"banana")
    echo "🍌 香蕉"
    ;;
"orange")
    echo "🍊 橙子"
    ;;
*)
    echo "抱歉，我不认识这个水果"
    ;;
esac
```

## 5.4 一个 case 匹配多个值（了解进阶）

```bash
#!/bin/bash
read -p "输入1-3: " n
case $n in
1|2)
    echo "你输入的是 1 或 2"
    ;;
3)
    echo "你输入的是 3"
    ;;
*)
    echo "其他数字"
    ;;
esac
```

# 第6章 read 获取输入（让脚本会"问话"）

## 6.1 概念
之前写的脚本都是"自说自话"，`read` 可以让脚本**停下来等用户从键盘输入**，再根据输入继续。

## 6.2 三种常用写法

```bash
read name                 # 等用户输入，回车后把内容存入 name
read -p "请输入：" name     # 先显示提示文字再等输入（最常用！）
read -t 5 name            # 限时5秒，超时没输入就跳过（t=time）
```

## 6.3 完整例子

```bash
#!/bin/bash
# 最基础：问名字
read -p "请输入你的名字：" name
echo "你好 $name，欢迎来到Shell世界！"
```

```bash
#!/bin/bash
# 进阶：让用户输入两个数并求和
read -p "请输入第一个数：" a
read -p "请输入第二个数：" b
echo "$a + $b = $(( a + b ))"
```

## 6.4 read 配合 if：输入+判断的经典组合

```bash
#!/bin/bash
read -p "请输入你的年龄：" age
if [ $age -ge 18 ]; then
    echo "成年人"
else
    echo "未成年人"
fi
```

# 第7章 for 循环（"我知道要循环几次"）

## 7.1 概念
需要**重复执行**某段代码时用循环。  
`for` 适合用在**你事先知道要循环几次 / 要遍历哪几个值**的情况。

## 7.2 语法一：遍历列表（最直观）

```bash
for 变量 in 值1 值2 值3 ...
do
    每次循环要执行的命令
done                # done 是结束标记，必须有！
```

```bash
#!/bin/bash
# 例1：遍历名字列表
for name in 张三 李四 王五 赵六
do
    echo "你好，$name"
done

# 例2：从1数到5
for i in 1 2 3 4 5
do
    echo "第 $i 次循环"
done
```

执行过程理解：第一次循环 `变量=张三`，执行 do 和 done 之间代码；第二次 `变量=李四`……直到列表里的值都用完。

## 7.3 语法二：C语言风格（从几数到几很方便）

```bash
for (( 初始值; 循环条件; 每轮变化 ))
do
    命令
done
```

```bash
#!/bin/bash
for (( i=1; i<=10; i++ ))
do
    echo "现在是第 $i 圈"
done
```

拆解三个位置：
- `i=1` → 从 1 开始
- `i<=10` → 只要 i 还小于等于10 就继续
- `i++` → 每转一圈 i 自己 +1

## 7.4 经典例题：求 1 加到 100

```bash
#!/bin/bash
sum=0                                  # 先准备一个"存钱罐"sum，初始0
for (( i=1; i<=100; i++ ))             # i 从1跑到100
do
    sum=$(( sum + i ))                 # 每圈把 i 累加进 sum
done
echo "1+2+...+100 = $sum"
```

关键理解累加：`sum=$(( sum + i ))` 意思是"把 sum 现在存的值 + 上 i，结果再存回 sum"，就像往存钱罐里一枚枚投硬币。

## 7.5 for 也能遍历命令的结果（进阶）

```bash
#!/bin/bash
# 把 ls 列出的每个文件名都打印一遍
for f in $(ls)          # $( ) 表示"先执行里面的命令，把结果拿来用"
do
    echo "找到一个文件：$f"
done
```

# 第8章 while 循环（"只要条件还成立，就一直转"）

## 8.1 概念
`while` 是**先看条件，条件为真就执行一次，执行完再看条件……**直到条件为假才停。
适合"不知道具体几次，只知道什么条件停"的情况。

## 8.2 语法

```bash
while [ 条件 ]
do
    命令
done
```

## 8.3 例子：while 求 1 加到 100

```bash
#!/bin/bash
i=1
sum=0
while [ $i -le 100 ]
do
    sum=$(( sum + i ))
    i=$(( i + 1 ))       # ⚠️ 千万不能忘！没有这行 i 永远不变 → 死循环
done
echo "1+2+...+100 = $sum"
```

## 8.4 例子：猜数字游戏（while 的经典用途）

```bash
#!/bin/bash
# 让用户一直猜，直到猜对才停
secret=7
read -p "请猜一个1-10的数字：" guess
while [ $guess -ne $secret ]
do
    echo "猜错啦，再试一次"
    read -p "请再猜：" guess
done
echo "恭喜你猜对了！"
```

## 8.5 ⚠️ 死循环警告（这节课最重要的安全意识！）

**什么是死循环**：如果 while 的条件**永远为真**，程序就会无限刷屏，停不下来。

```bash
#!/bin/bash
# ❌ 危险例子：忘了让 i 变大，会疯狂刷屏
i=1
while [ $i -le 100 ]
do
    echo "数字 $i"     # i 永远等于1，条件永远成立 → 死循环
done
```

**救命方法**：
```bash
Ctrl + C      # 强制中断正在运行的命令/脚本
```

⚠️ 练习时如果屏幕突然疯狂滚动，**马上按 Ctrl+C**，不会损坏系统，放心按。

## 8.6 for vs while 怎么选

| 情况 | 用哪个 |
|------|--------|
| 知道要循环几次 / 遍历固定列表 | for |
| 次数不定，靠条件什么时候成立才停 | while |
| 想一直循环直到用户输入特定值 | while |

# 第9章 综合大案例（把今天6节课串起来）

## 9.1 综合案例1：成绩评级 + 数字统计

```bash
#!/bin/bash
# 用到了：read输入 + if判断 + for循环 + 运算
read -p "请输入你的成绩：" score

# —— if 分支判断等级 ——
if [ $score -ge 90 ]; then
    echo "评价：优秀 🏆"
elif [ $score -ge 60 ]; then
    echo "评价：及格 ✅"
else
    echo "评价：不及格 ❌"
fi

# —— for 循环求 1+...+100 ——
sum=0
for (( i=1; i<=100; i++ ))
do
    sum=$(( sum + i ))
done
echo "顺便算一下：1+2+...+100 = $sum"
```

## 9.2 综合案例2：水果翻译机（read + case）

```bash
#!/bin/bash
read -p "请输入水果英文名：" fruit
case $fruit in
"apple")    echo "苹果" ;;
"banana")   echo "香蕉" ;;
"orange")   echo "橙子" ;;
*)          echo "不认识，换个试试" ;;
esac
```

## 9.3 综合案例3：数字雨倒计时（while + read + if）

```bash
#!/bin/bash
# 输入一个数字，从它倒数到0
read -p "输入一个开始倒数的数字：" n
while [ $n -ge 0 ]
do
    echo "倒计时：$n"
    n=$(( n - 1 ))
    sleep 1          # 暂停1秒，让输出慢一点（sleep=睡觉）
done
echo "时间到！🚀"
```

# 第10章 易错点自查表（报错先查这里！）

| # | ❌ 错误写法 | ✅ 正确写法 | 原因 |
|---|-----------|-----------|------|
| 1 | `[条件]` | `[ 条件 ]` | 中括号两边**必须有空格** |
| 2 | `if ...` 没写 fi | 结尾写 `fi` | fi 是 if 的结束符 |
| 3 | `case ...` 没写 esac | 结尾写 `esac` | esac 是 case 的结束符 |
| 4 | `for/while ...` 没写 done | 结尾写 `done` | done 是循环结束符 |
| 5 | `sum=sum+1` | `sum=$(( sum + 1 ))` | Shell 不会自动算数 |
| 6 | `[ 10 = 10 ]` | `[ 10 -eq 10 ]` | 数字比较要用 -eq 那套 |
| 7 | `name =tom` | `name=tom` | 变量赋值等号两边**不能有空格** |
| 8 | 忘了 `#! /bin/bash` | 第一行写上 | 声明解释器，防止奇怪报错 |
| 9 | 忘了写 `;;` | 每支 case 结尾写 `;;` | 双分号是 case 分支的结束 |
| 10 | while 忘写 `i=$((i+1))` | 记得让条件变量变化 | 否则死循环，按 Ctrl+C 救命 |
| 11 | 字符串比较用 `-eq` | 字符串用 `=` | 数字和字符串的运算符不同 |
| 12 | 单引号里用变量 | 双引号里用变量 | 单引号不翻译 $，双引号才翻译 |

### 练习1（if + read）
写一个脚本：让用户输入一个成绩，>=90 输出"优秀"，60-89 输出"及格"，<60 输出"不及格"。

```bash
# 参考思路
#!/bin/bash
read -p "请输入成绩：" s
if [ $s -ge 90 ]; then
    echo "优秀"
elif [ $s -ge 60 ]; then
    echo "及格"
else
    echo "不及格"
fi
```


## ✅ 今天六节课，浓缩成六句话
1. **test / [ ]**：判断的"眼睛"——数字用 -eq/-gt，字符串用 =，文件用 -e/-f/-d
2. **if**：根据条件做不同的事，结尾别忘 **fi**
3. **case**：变量等于不同固定值时的开关，结尾别忘 **esac**，每支结尾 **;;**
4. **for**：知道次数就用它，`for ((i=1;i<=100;i++))` 很常用
5. **while**：条件成立就一直转，**别忘让变量变化**，死循环按 **Ctrl+C**
6. **read**：让脚本停下来等用户输入，`read -p "提示语" 变量`
   （再加上 `$(( ))` 算数、变量加 `$` 取值，就够你写很多小脚本了）
