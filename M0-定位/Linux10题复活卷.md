## 1. 通用交付标准（"四件套"的完整定义）

每题都照此交：

1. **命令**：从终端 `history` 里照抄，不许凭记忆重打；
2. **真实输出**：命令和输出**同框**粘贴（代码块）或截图，要能看到 `[root@...]#` 提示符；多步题分步骤贴；
3. **一句解释**：每个选项/参数干嘛，用自己的话（从教程抄来的解释 = 不算）；
4. **自评**：独立 / 查资料 / 卡住；错的题补"现象 → 根因 → 修法"。

补充规则：

- **输出为空怎么办**：如实写"输出为空"→ 造测试数据（touch / echo / logger 等，方法自选并写明）→ 重跑，贴非空输出。**"空着交"和"假装有"都比"造数据重跑"差得多。**
- **诚实分层**：查了资料、问了导师 → 标"查资料"，**不扣分**；冒充"独立" → 该题记 0；
- **截图要求**：整窗截图，含提示符＋命令＋输出；看不清按未交处理；
- 交卷前，把 §0 和每一题的勾选清单全部勾满，再喊口令。
