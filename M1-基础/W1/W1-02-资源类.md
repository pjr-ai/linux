## 定位 —— 怎么一步步缩小范围（每条命令＋输出，写清"为什么用这一步"）

1. `top`：找占用 CPU 的元凶（按 P 以 CPU 排行）
2. `kill -9 <PID>`：强制杀死进程（PID 从 top 输出里抄）
3. `top`：再看一眼，确认进程被杀死、CPU 回落

## 复盘 —— 下次遇同类怎么更快（≥3 行，要具体到命令）

```bash

kill -9 <PID>    # 强制杀死进程（注意：kill 吃的是 PID）
top              # 再次查看 CPU 占用率，确认回落
```
