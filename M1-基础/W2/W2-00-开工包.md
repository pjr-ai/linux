## 卡 1 · 磁盘类【建议首做 · 材料现成】
**场景**：盘满了；加餐——**删了文件、空间不还**（面试高频）。
**造**（先 `df -h` 看余量，造的文件别超余量 1/3）：
- 基础：`fallocate -l 2G /opt/bigfile`（或 `dd if=/dev/zero of=/opt/bigfile bs=1M count=2048`）→ `df -h` 看它涨上去
- 加餐（两个 SSH 配合）：`tail -f /opt/bigfile` 先把它挂住 → `rm /opt/bigfile` → `df -h` 竟然没变、`du` 也找不着 → 上 `lsof +L1` 揪出"还拽着文件的进程" → `kill` 掉 → `df -h` 复验
- 彩蛋（可选）：inode 满了也报"空间不足"——`df -i` 看一眼，你 9.10 实验里碰过
**弹药**：`df -h` · `du -sh` · `du -h --max-depth=1` · `find / -xdev -size +100M 2>/dev/null` · `lsof +L1` · `kill` · `truncate -s 0 文件`（清空但不删除）
**学习源**：你 9.10 的磁盘实验（升级重写）＋ `man lsof`
**预算**：3–4h

## 卡 2 · 权限类【你的旧伤，正面对线】
**场景**：permission denied——脚本跑不了 / 目录进不去。
**造**（先 `whoami`；如果自己是 root，建个普通用户来体验：`useradd -m tester` → `su - tester`，玩完 `exit` 回来。root 基本无视权限，所以必须借普通用户）：
- 没 +x：写个 `hello.sh`（`#!/bin/bash` ＋ `echo hello`）→ `./hello.sh` 被拒 → 修
- 目录没 x：`chmod 644 某目录` → `cd` 进不去，但 `ls` 还能看到名字（r 和 x 各管什么＝考点）→ 修
- 属主：root 的文件让普通用户改 → 被拒 → `chown` 修回来
**弹药**：`whoami` · `id` · `ls -l` · `chmod u+x` / `chmod 644` · `chown 用户:组` · `useradd -m` · `su - 用户` · `stat`
**学习源**：韩顺平权限笔记 ＋ 旧答卷里 644/755 那题（当时答偏成 -R——这周掰正）
**预算**：2.5–3.5h

## 卡 3 · 定时任务类
**场景**：cron 到点不执行——终端里跑得好好的脚本，挂上 cron 后它就是不动。
**造（三步剧：道具 → 基线 → 弄坏，然后查回来）**：
1. **道具**：写个干活的小脚本 `/opt/cron-job.sh`（内容＝`#!/bin/bash` ＋ `date >> /tmp/cron-job.log`）；`chmod +x` 后手跑一次（`/opt/cron-job.sh` → `cat /tmp/cron-job.log` 长一行）。
2. **基线**：`crontab -e` 挂上 `* * * * * /opt/cron-job.sh`（默认开 vi：`i` 写、`Esc` 后 `:wq` 存）→ 等 1–2 分钟：日志每分钟长一行＋`/var/log/cron` 里 CROND 每分钟点名 ＝ **“好”长什么样，先记住、先截证**。
3. **弄坏**（二选一，建议先 A；B 当加餐）：
   - **A 没执行权限**：`chmod -x /opt/cron-job.sh` → 日志不再长。
   - **B 命令找不到**：脚本里改用一条 /usr/sbin 下的命令（先 `which ss` 确认位置），如 `ss -lntp > /tmp/ports.txt` → 终端能跑、cron 下文件是空的。
4. **查回来**：当“不知情的人”，从现象出发：定位 → 根因 → 修复 → 复验，四段照写；截图三组：好的、坏的、修好的。通用手法＝**复现＋对齐**：把 crontab 里那条命令原样手敲一遍，两边一字不差地对。
**弹药**：`crontab -l / -e` · `systemctl status crond` · `/var/log/cron` · `journalctl -u crond` · `which` · `echo $PATH` / `env` · `chmod +x` · 绝对路径 · `>> 日志 2>&1`（把报错收出来）
**雷**：`crontab -r` 一键清光所有任务——动手前先 `crontab -l > /tmp/cron.bak`（顺便练备份习惯）；每分钟的活截完证记得停（`crontab -e` 删行）。
**学习源**：你笔记里"定时任务"×2 ＋ `man 5 crontab`
**预算**：3–4h（含基线 ≈30–40min）

## 卡 4 · 网络类
**场景**：服务"外面"连不上——本机通、别的机器不通。
**造**：`python3 -m http.server 8080 --bind 127.0.0.1` → 本机 `curl 127.0.0.1:8080` 通 → 换本机 IP 再连（`curl <本机IP>:8080`，IP 用 `hostname -I` 拿）不通 → `ss -lntp` 看出"绑在了 127.0.0.1" → 根因 → 重起绑 `0.0.0.0` 复验（让 Windows 那边也试一次）
- 进阶（看环境）：`systemctl status firewalld` 在跑 → 用 `firewall-cmd` 造"防火墙挡端口"再修
- ⚠ 改网卡配置文件有断 SSH 风险——先打快照；真断了用 VMware 控制台救
**弹药**：`ss -lntp` · `ip a` · `ip r` · `ping` · `curl` · `hostname -I` · `firewall-cmd --list-all`
**学习源**：M0 网络件（ping/curl 两连问）＋ 网络笔记
**预算**：3h
